# Sectors

**A Sector is one pocket of humanity** (canon, 5 Nov 2026): a span of worlds, often across several galaxies, whose people share local powers, local peoples, a history and the same Celestial messes. Humanity is several sextillion people on trillions of worlds, so there are more Sectors than anyone has counted. Nobody knows the whole; everyone knows their Sector.

Every campaign is set in a Sector. Two things are the same in all of them:

1. **Anti-Heaven Operations Command** has chapters there.
2. **The Celestials' rules hold:** hands off, create but never erase, appear only by cause, the Unspoken Name, the Veil exception (World Bible).

Everything else (powers, peoples, wars, calendars, what's normal) is local.

## Sector sheet template

A Narrator, human or AI, can build a new Sector by filling this in. Keep each field short: a line or a small table.

| Field | What goes in it |
|---|---|
| **Name** | What its people call it, never a real-Earth name |
| **Span** | Which worlds, how many galaxies, the notable places |
| **Calendar** | Whose year count the Sector uses, and from what event |
| **Powers** | 4–8 local factions, each with *wants* and *fears* (see the Earth Sector's [faction web](Factions.md) for depth) |
| **Tensions** | 2–5 conflicts that run through the powers; each one is a campaign engine |
| **Peoples** | Who lives here besides ordinary humans: Celestial-made peoples, robots, beasts that talk. Which are playable (race selection comes later) |
| **Celestial messes** | Abandoned plots, pact Celestials, curses, monsters that can't be erased. At least one should be a mystery the locals have wrong |
| **Anti-Heaven chapters** | 2–3 example chapters, using the chapter template in [Factions.md](Factions.md) |
| **Texture** | Money, guns, magic, tech: what's everyday and what's rare. Which of Sigil, Soul and Blessing magic are common here |
| **What locals believe** | The official history, and what it leaves out |
| **Origins** | 6–14 human upbringings for character creation (format below) |
| **Starting hooks** | 3–5 first scenes, each starting from a Celestial's mess |

## Origin format

An origin is where a character grew up. It's chosen at creation after the Sector, and before race once races exist. It carries **no numbers**: it tells the Narrator what the character knows, who they know and how people react to them.

| Part | Content |
|---|---|
| **Home** | Where, in a line |
| **Upbringing** | What growing up there was like, in a line or two |
| **You know** | The local knowledge the Narrator treats as familiar |
| **People see you as** | The first impression you make on everyone else, good and bad |
| **Skills it suggests** | Three skills, for creation presets |
| **Traits that fit** | Existing traits from `data/traits.json` that belong to this upbringing |
| **Hook** | One person or debt from home the Narrator can pull on |

**Local knowledge rule** *(provisional, Narrator-owned)*: checks about your own origin's places, customs and people are set one step easier on the TN ladder (Hard becomes Standard, Standard becomes Easy). The engine doesn't change; the Narrator sets the TN.
