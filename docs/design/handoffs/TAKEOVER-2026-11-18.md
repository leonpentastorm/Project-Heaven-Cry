- Shell: Git Bash; `export PYTHONUTF8=1`; `python` (not python3).
- Gate: `python tools/check.py` (ALL GREEN); `REPLAY_FULL=1 npm test -w @phc/engine -- replay-hash` (29);
  `npm run balance`.
- Browser suites: `export NODE_PATH="C:/Users/Izacarl/Documents/Project Heaven Cry/node_modules"`, then
  `python tools/e2e.py <suites>` or `all --jobs 4`; `KEEP_SHOTS=1` keeps `.check/e2e/shots/<suite>/` (a passing run
  deletes them otherwise). It owns port 8787 and stops every wrangler on the machine: one lane at a time.
  `capture-skills` screenshots the 27 skill pages into `.check/capture/skills/`. `capture-all.mjs` is an unfinished
  draft (not registered): its skill-page selector is wrong.
- After `npm run assets` or `build.py --web`, discard line-ending-only changes in
  `apps/web/src/game/{assets,eyelines,protodata}.json` (`git diff --ignore-cr-at-eol --quiet && git checkout -- .`).
- Re-record recorded tables only on purpose: `GOLDEN_RECORD=1 REPLAY_RECORD=1 REPLAY_FULL=1 npm test -w @phc/engine`.
- Deploy (in the release tree, clean, `origin/main` an ancestor of HEAD): `npm run assets`;
  `python design/canvas-build/build.py --web`; `npm run build`; push HEAD to `develop` and `main`; make a scratch
