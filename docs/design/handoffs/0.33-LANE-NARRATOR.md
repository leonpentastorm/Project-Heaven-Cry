## Not built, and why

- **A per-entry "required" check on the desk.** The AI's tool marks every key of its older fields required (a strict
  tool); a person need not fill a loot's rarity or name. The desk leaves empty values out and the engine checks every
  field, as it does the AI's (an invalid entry is dropped, as for the AI). A hook with no line is dropped silently.
- **Pickers for the open shapes** (a trigger's spawn list, a drop table, ground items): JSON fields, because the AI's
  tool gives them no shape. When the tool gets a shape, the desk follows.
- **The Narrator's view in a fight** was already whole (rules 1.80); nothing changed there.
