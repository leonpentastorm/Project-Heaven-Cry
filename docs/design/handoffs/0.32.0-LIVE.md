## What was proved, and how

Run at the shipped commit by an agent that did not build it:

- `python tools/check.py`: ALL GREEN (engine 5057 tests, web 1706).
- Replays: 29 of 29, none re-recorded.
- The full browser run (`e2e all --jobs 4`, 79 suites, 31.8 minutes): 78 green together; `voice` red in the run and green alone (a timing check; not read further).
- A review of the fix pass's engine, data and client changes by three readers: no blocker.

## What was NOT proved

1. **Nobody played it by hand.** Every proof is a test or a still picture. The lead looked at only a few screens itself; animations (the camera glide, the effects) were seen only as stills.
2. **The live site was checked for its version string only.** No fight was played on live after the deploy.
3. **Co-op input delay** (the 2 to 3 seconds Vietnam to a US host) is unchanged: it is the network and where the room lives, measured locally at about 52 ms. It needs a measurement on live from two places.
4. `voice` passes only when run alone.

## Two real faults the last pass found and fixed (worth a look in play)

1. **Every new character's door was dead in the first Survival fight** (Picture and Bond answered "Not now" during the approach). Fixed in the engine with a reducer test; a new browser suite (`doors-new`) walks a new Rigger through choosing forms and Picturing, and a new Mender through a Bond.
2. **The fight camera jumped every turn** (the SIGHTLINE switch resized the map window each turn). Fixed in the client.

## Known faults shipped (in the roadmap)

- **The your-turn card can be drawn off screen on a window under 1000 px wide** when it comes from the right. A click or a key dismisses it and play goes on. Confirmed in code, not blocking.
- An old mid-fight save holding both Still Standing and Bite the Bullet may give borrowed time to the wrong perk on load (minor, not verified).
- The 0.32.x polish list in the roadmap (the screenshot pass's small faults).
