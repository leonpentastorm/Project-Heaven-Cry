# The text pass of 11 Nov 2026: where a card and the game disagreed

1,411 player-facing texts were rewritten in plain language (data and code), each lane then checked line by line against the engine by a second reader. This is the list of places where the old text and the code said different things. In every case the **text now says what the game does**; nothing in the engine was changed. Each line needs one of two rulings: the game is right (nothing to do), or the old text was the rule and the engine is the bug.
