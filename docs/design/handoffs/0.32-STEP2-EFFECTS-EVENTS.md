# 0.32 step 2: the effects lane's engine events and the standing vow (19 Nov 2026)

Merged `wip/0.32-roadmap` and `wip/0.32-effects` into `release/0.32` (`b290bc3a5`, no conflicts); built the six engine
events the lead approved (spec rules 1.72, items 5700-5705) and step 3's leftovers (5706-5707). Owed work is in
`docs/ROADMAP.md` (0.32, Shared pieces and Effects), not here.

## Built from

| rule | existing primitive that carries it |
| --- | --- |
| 5700 a cleanse says what it removed | `emitFx` with the existing `boon` kind, word `cleanse` and `cond` (as the Sigil's CLEANSE); in the `cleanse` op (`effects/triggers.ts`) |
| 5701 a Bond the tie op ends is an event | `emitFx` with the existing `stance` kind (what `untie`, unit, target, how = kind); `untie()` (kit.ts) unchanged, its pick wrapped to collect the ended ties |
| 5702 a prayer's hurt carries its element | `withElement` (magic.ts) around `harm` in `faith.ts harmLine` (the damage type as the element; the client's `elementId` reads aliases) |
| 5703 Everyone Home's shields numbered | `grantShield` as before (the number unchanged) and `mendShown(cb, v, 'shield', ...)` (effects/core.ts), the one mend's effect |
| 5704 a state-only prayer says its name | `emitFx` with the existing `stance` kind (what `prayer`, `word` the data name), decided from the fx the prayer itself sent (`stateOnlyShown`, faith.ts, not exported) |
| 5705 the standing vow | `faith/vow` (the existing action) out of a fight; the existing `combat_start` hook in faith.ts swears it; one copy of the swear rule (`vowRefusal` + `swearOn`, split out of `swearVow`, not exported); `survival.json rest.vow_change` read by `vowChangeNow`; `Character.vowStanding` (a saved field; absent on old saves); `FaithView.standing` and `vowChange` (fields on the existing view) |
| 5706 Tug beside you says so | data only: a `use` op row (no limit: nothing but its `say`) with the existing predicates `target: ally` and `target_within: 1` |
| 5707 NOW PLAYING chip | web only (`game/music.tsx`) |

## Needs a new primitive

None. No trigger, predicate, op, hook, resource, stat, cost site or export was added (`docs/ENGINE-HOOKS.md`: the
`stance` kind gained the field `word`, the `boon` kind one more site; 675 primitive exports, unchanged).

## Calls made (for Leon to reverse)

- Out of a Survival run the standing vow changes any time out of a fight (spec 5705, PROVISIONAL).
- The base `stance` handler (`fx/play.ts`) no longer says OVERWATCH for a `what` no module draws (it says the row's
  word, or nothing): `quicken` and `link` stances used to float OVERWATCH by mistake.

## Replays

Re-recorded on purpose (13 tables in `test/golden/replays.json`): only the effects list moved. All 24 dumped final
states were compared with and without this change, `fx`/`fxSeq` stripped: equal.
