## The incident: an unreleased build was live for about ten hours

At 05:38 UTC on 20 Nov a builder ran `python tools/deploy_site.py --help` to read the script's options. The new script ignored the word and deployed. Live served wave 1 of 0.33 plus an untested loading change, **still labelled 0.32.0**, until 0.33.0 replaced it. You chose to leave it rather than roll back. **Any outside playtest run after 05:38 UTC on 20 Nov was on that build, not on 0.32.0.**

Fixed: the script deploys only with `--deploy` and refuses any argument it does not know (tested: `--help`, no argument and an unknown word all print the help and deploy nothing). Every brief since forbids running it. The lead saw the incident only in the integration report three hours later: builders are now told to report anything that touches live at once.
