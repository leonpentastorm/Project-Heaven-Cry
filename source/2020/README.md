# 2020 source material

Original Project Heaven Cry material, kept for reference. Rules here are **superseded** by `docs/rules/PHC-Core-Rules-v1.0.md`.

| File | What it is |
| --- | --- |
| `Official_EPCCG_Trait_Edition_2.docx` | The 2020 trait book (Vietnamese). Rebalanced and rewritten in-universe as EPCCG: Trait Edition, Revision 2 (74 traits) → `data/traits.json`. |
| `Official_EPCCG.docx` (not in repo) | The Vietnamese Starter Edition guide. Its English edition is the lore base, in `docs/lore/EPCCG-Player-Character-Creation-Guide.md`. |
| `english/EPCCG-Trait-Edition-2020-EN.md` | English edition of the 2020 trait book (27 of its 28 traits; one bigoted trait deliberately not translated). Superseded by Trait Edition Revision 2 (74 traits, `data/traits.json`), which removed its pop-culture references. Kept as history. |
| `screenshots/recovered-*.jpg` | Phone screenshots of recovered 2020 perk and magic notes. Their content is transcribed in `docs/design/Recovered-Design-Notes-2020.md`. |

Not in this repo (they live in the claude.ai Project "Project Heaven Cry"; add them here if you want them versioned):

- `PHC_Official_Character_Sheet.xlsx`: the blank character sheet (Combat Sheet + Character Bio). Its fields are reproduced in the story-mode character panel tabs.
- `M1.4_8R4-D83-RRY_A5.xlsx`: MPAT's sheet. Summarised in English in `docs/lore/MPAT-and-M813.md`.
