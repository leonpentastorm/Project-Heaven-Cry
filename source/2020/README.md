# 2020 source material

Original Project Heaven Cry material, kept for reference. Rules here are **superseded** by `docs/rules/PHC-Core-Rules-v1.0.md`.

| File | What it is |
| --- | --- |
| `Official_EPCCG_Trait_Edition_2.docx` | The 2020 trait book (Vietnamese). Rebalanced and rewritten in-universe as EPCCG: Trait Edition, Revision 2 (74 traits) → `data/traits.json`. |
| `Official_EPCCG.docx` | The Vietnamese Starter Edition guide. Its English edition is the lore base, in `docs/lore/EPCCG-Player-Character-Creation-Guide.md`; its skill write-ups are game text in `data/skills.json` (`epccg`). |
| `PHC_Official_Character_Sheet.xlsx` | The blank 2020 sheet: Combat Sheet (27 skills, body slots Head / Head Acc / Torso Outer / Torso Inner / Lower Torso / Legs / Hands / Footwear / Veil, backpack, inventory with weight, Acquired and Achieved perks, weapons mastery by kills, Sigils, Outbursts, Blessing, derived combat stats) and Character Bio (original name, origin, last dream, favourite song, trivia, history). |
| `M1.4_8R4-D83-RRY_A5.xlsx` | MPAT's 2020 sheet (Vietnamese trivia and history). Summarised in English in `docs/lore/MPAT-and-M813.md`. |
| `english/EPCCG-Trait-Edition-2020-EN.md` | English edition of the 2020 trait book (27 of its 28 traits; one bigoted trait deliberately not translated). Superseded by Trait Edition Revision 2 (74 traits, `data/traits.json`), which removed its pop-culture references. Kept as history. |
| `screenshots/recovered-*.jpg` | Phone screenshots of recovered 2020 perk and magic notes. Their content is transcribed in `docs/design/Recovered-Design-Notes-2020.md`. |

All three were added in Nov 2026 from Leon's 2020 folder. The prototype's Status and Gear tabs borrow the sheet's Karma, Reputation, Leadership, body slots and carry load.
