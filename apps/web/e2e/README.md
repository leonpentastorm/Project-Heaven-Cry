# End-to-end tests

Two real browsers play a session through the room relay, with the scripted Narrator (no API key needed).

- `two-players.mjs`: host opens a room, both make characters through the creation screens, the session starts, both speak, the Narrator calls a check (rolled on the dice table), a fight runs to the end on the grid, the story resumes, Level up opens.
- `turn-card-side.mjs`: the turn card's CARD SIDE in its customise dialog (Auto, Left, Right): Right brings the next card in on the right, Left on the left, kept after a reload, Auto clears it.
- `tabs.mjs`: the combat action tabs in the Proving Ground at 1440×900 and 1280×720 (every tab, the glyph keyboard and the Outburst design cards open; the grid and Confirm stay on screen with no page scroll), keys 1–6 and arrows, the turn card and a hostile click switching tabs, the last tab remembered, and a 900 px window with the action dock at the bottom. Shots: `tabs-*.png`. Combat tests click actions with `pickAction()` from `lib.mjs`, which opens the tab that holds the action first.
- `mapzoom.mjs`: the combat map's size in a Proving Ground fight: Auto at 1280×720, 1600×900, 1920×1080 and 2560×1440 (bigger screens, bigger map; it always fits the window height and the action zone keeps 400 px), − / 100% / + / Auto, the − and + keys, Ctrl + wheel over the map, 250% scrolling inside its zone, kept after a reload, Auto following the splitter. Shots with `SHOTS=dir`: `mapzoom-*.png`.
- `layout.mjs`: the combat screen's adjustable layout in a Proving Ground fight: the splitter (drag and arrow keys; the action zone keeps its 360 px), the combat log dragged into the action zone, the legend above the map, the action menu dragged left to swap the sides, all kept after a reload; Hide panel (H) brings the log back under the map; ↺ Layout resets; narrow windows hide the splitter and grips. - `slate-title.mjs`: the title at 1280×720, 1440×900, 1920×1080, 2560×1440, 900×800 and 390×844: the words never clip, the back and mid key art load, parallax moves, Wick runs / idles / says hello, hover works on other rows during his hello, and the first-key greeting. Shots: `slate-title-*.png`.

Run against local dev (`npm run dev -w @phc/server` after `npm run build`) or the live site:

```bash
node apps/web/e2e/two-players.mjs
BASE=https://project-heaven-cry.leonpentastorm.workers.dev node apps/web/e2e/reconnect.mjs
```

**Proxies:** with `BASE` and `HTTPS_PROXY` both set, `lib.mjs` sends Chromium through `HTTPS_PROXY` (an agent sandbox's only way to the live site), with loopback bypassed. A `BASE` on this machine (`127.0.0.1` or any `127.x`, `localhost`, `::1`) never goes through the proxy, so a local `wrangler dev` runs the same with `HTTPS_PROXY` set or not (such a proxy only takes CONNECT to the outside, and every local test used to stop at the title):

```bash
BASE=http://127.0.0.1:8797 node apps/web/e2e/ground.mjs   # HTTPS_PROXY may stay set
```

Screenshots land in `apps/web/e2e/shots/`. Playwright is loaded with `require('playwright')`.
