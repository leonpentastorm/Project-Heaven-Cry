# Heavenprint New Faces — 27 character portraits

The latest named-character Heavenprint collection, now reserved for character portraits. Includes 27 original 800 × 1000 PNGs, unchanged from the approved New Faces set, plus its labelled overview.

The original core / attribute / skill filenames remain stable so existing references still work. `manifest.json` maps those historical skill IDs to the invented character names. The figures include PHC people and automata. Their clothing, environments, natural material colours and old lighting groups remain intact.

For new character paintings use the Heavenprint character chapters in `../../style-guide/v1.2/`. For current player-skill slots use `../../skills/poc4-palette-v3/`. The newest abstract-skill palette does not retroactively recolour these character paintings.
