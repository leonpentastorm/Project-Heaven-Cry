# PHC — POC 4-derived abstract skills / Palette v3

Current production set: 27 individual 800 × 1000 RGB PNGs. Readable, faceless humanoid gestures in broken gouache and ink. Black background, cream body, one attribute hue for all other pigment and shading.

## Colour update — 5 November 2026

- Endurance: bold crimson #CC2435.
- Strength: orange #F68A38, formerly Agility's colour.
- Agility: gold #E3BF51, formerly Strength's colour.
- Expression retains deep petrol-blue #075369; Virtue retains dark mulberry #86234E.
- Perception, Intelligence, Insight and Determination retain their previous colours.

The nine Body cards were generated as colour edits, retaining their established compositions. The other 18 PNGs are byte-for-byte identical to Palette v2. Previous sets are preserved separately. Hex values describe pigment direction rather than indexed output guarantees.

Files are organised by core / attribute / skill. The manifest maps each file to its meaning and colour. Preview sheets are review aids; individual PNGs are the game assets. Human-style skill paintings are now kept separately as character portraits.
