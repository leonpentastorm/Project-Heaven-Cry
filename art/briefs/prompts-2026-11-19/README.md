# The prompt pack, 19 November 2026

This folder holds the paste-ready prompts for everything in [`../ART-REQUESTS-2026-11-19.md`](../ART-REQUESTS-2026-11-19.md),
the art list for 0.31.x, 0.32 and the Items 2.0 plan. The list says **what** is wanted and why. This pack says **how to ask
for it**: for each picture there is a style block for its art mode, the references to attach (repo paths), the file name to
save as, and one fenced prompt to paste. Files 01 to 08 start with their style block, and every entry carries its id, its
save path and its prompt. File 09 is the exception: it uses the style block and family paragraphs of
[`../GPT-PROMPTS-2026-11-13-gear.md`](../GPT-PROMPTS-2026-11-13-gear.md) (sections 1 and 2), and its prompts are quoted
lines rather than fenced blocks.

Use one image per prompt. Paste the file's style block for the mode, then the entry's prompt, and attach what the entry
names. Nothing in this pack is final until Leon approves the delivered picture.

## Handing pictures back

- **File names:** use exactly the **Save as** path of the entry, and do not rename. Wick icons and signs go in
  `art/icons/perks/`, `forks/`, `moves/`, `conditions/` and `banners/` (kebab-case). Gear paintings go in `art/icons/gear/`
  as `weapon-<id>.png`, `shield-<id>.png`, `armour-<id>.png` or `mod-<id>.png`, and grade pictures as
  `<stem>--<tier>.png` (`fine`, `masterwork`, `relic`, `celestial`). Figment portraits go in `art/portraits/figments/` and
  kit pieces in `art/sprites/kit/<setting>/`.
- **Format:** PNG with alpha. Use 1024 x 1024 for Wick icons, signs and gear paintings, 800 x 1000 opaque for the Figment
  portrait, 256 x 256 for kit sprites and 1024 x 1024 seamless for kit grounds. Wick icons and signs are pure white ink on
  transparency.
- **Delivery:** for gear, deliver one contact sheet per family or per grade set, each picture checked at 64 and 32 px on
  `#10151F`. Every picture is a review candidate until Leon approves it.
- **Intake (Claude):** add the catalog entries in `art/catalog.json`, then run `python3 tools/rehash_art_checksums.py` and
  `python3 tools/validate_art.py`. The validator checks the catalog, the checksums and the PNGs (white ink, alpha). Then
  run `npm run assets`. Kit grounds are also checked with `python3 tools/art/kit_seams.py --sheet <dir>`. A replaced
  picture's old file goes to `art/_archive/`.
