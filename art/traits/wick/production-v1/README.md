# Wick trait production — version 1

New trait icons are delivered incrementally from [the production brief](../../../briefs/wick-production-icons.md). The approved master and three approved test designs remain in their existing collections; the seven revisions are in [round 2](../test-set-1/revisions/README.md).

Every new icon has a 1024 × 1024 pure-white transparent master, 256/128/64/56/48/44/40 px exports, a catalog entry and a source hash in `manifest.json`. Review sheets in `previews/` show each batch at actual UI sizes and on light/dark surfaces. Labels appear only in review layouts.

See [production progress](../production-progress.json) for the current delivered count. Each new icon is shown in chat and pushed on its own, as requested by Leon. New art remains `review-candidate`, `production_approved: false`; continuous delivery does not certify visual approval.
