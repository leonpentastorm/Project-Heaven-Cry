# New Faces — world characters

27 named original characters, each prompted to fit the essence of one skill. A pool for random NPCs, and an approved Heavenprint style anchor. Names are proposals, not canon. All three character sets were first painted as skill icons; they are now character portraits. See [`../README.md`](../README.md). Includes 27 original 800 × 1000 PNGs, unchanged from the approved New Faces set, plus its labelled overview.

The original core / attribute / skill filenames remain stable so existing references still work. `manifest.json` maps each file to its character name. The figures include PHC people and automata. Their clothing, environments, natural material colours and old lighting groups remain intact.

For new character paintings use the Heavenprint character chapters in `../../style-guide/v1.3/`. For current player-skill slots use `../../skills/poc4-palette-v3/`. The newest abstract-skill palette does not retroactively recolour these character paintings.
