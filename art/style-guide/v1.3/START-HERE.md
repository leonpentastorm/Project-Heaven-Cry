# PHC Artwork — Start Here

Version 1.3 • 5 November 2026

## What changed in 1.3
Trait **and perk** icons are pure white. Skill pigments are unchanged, but the game UI uses each attribute's contrast-safe `ui_ink` from palette.json. Wick is now canon: the EPCCG's mascot, drawn after the 258th Medical Unit's automata. First-Patch Revival is the EPCCG character set. See CHANGELOG.md.

# Current art modes / read first

VERSION 1.3 • 5 NOVEMBER 2026

## Character portraits and world illustrations
Use the Original 27 and New Faces sheets for Heavenprint paint, expressive believable faces, restrained stylization, lore equipment and material rendering. The latest New Faces collection is now a CHARACTER asset library. Its old skill labels are archival identifiers, not instructions to put a different person in every player-skill slot. **First-Patch Revival is the EPCCG cast:** its 27 portraits are the people quoted in the EPCCG's skill entries (Sanchez, Knight Jiren, Professor Avdol, Sister October and the rest). When painting a named EPCCG character, use that portrait as the casting reference and the EPCCG passage as the brief.

## Player skill portraits
Use the newest POC 4-derived gestural collection, Palette v3. A skill is an aspect of the player: faceless, incomplete humanoid brush forms with distinct stature and a readable action. Use only black background, cream body marks and the relevant attribute hue. Sections 15–17 define this mode. The user's latest colour changes are included here.

## Wick trait and perk icons
Use the exact approved Mind Without Fog icon. Keep the cape, lantern heart, pixel-screen face and lively asymmetry. Traits and perks both use pure white flat ink. This is an independent graphic mode, not a miniature painted skill portrait.

## Reference priority
Current user brief first. Then the reference for the correct art mode. World documents supply facts. This guide supplies visual defaults. Historical labels and palettes on approved character sheets do not override the current skill palette.

This package makes the decisions portable; attach its relevant guide and images in a new chat. A style name alone cannot guarantee identical generation.

Read the combined Markdown bible (the v1.2 PDF is the illustrated edition and predates these 1.3 changes) and inspect the references for your art mode. The current skill colours are in palette.json.
