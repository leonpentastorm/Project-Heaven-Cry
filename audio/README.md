## The fight music (Project Heaven Cry OST)

The engine picks the track (`fightTheme` and `musicFor` in `packages/engine/src/music.ts`); the browser plays it from
the file through Web Audio (`apps/web/src/game/ost.ts`). The files end on Suno's hard cut, so they are not looped as
files: each pass runs from a loop-in to a loop-out point and crossfades into the next pass (equal power), which makes
the loop seamless. The points live in `OST_FILES` in `ost.ts`:

| Track | Loop in | Loop out | Seam |
|---|---|---|---|
| Gunline | 0.4 s (silence before it) | 67.7 s (the final hit's tail starts) | 1.2 s |
| Heaven Falls | 0.1 s | 135.5 s (the cut) | 1.5 s |
| Last Rounds | 0.1 s | 81.0 s (heartbeat and static at both ends) | 1.2 s |

Changing track crossfades over 1.2 s; the fight's end fades it out. A replacement file with a different length needs
new loop points.

Web copies: `ffmpeg -i <master> -map 0:a -c:a copy -map_metadata -1 -id3v2_version 0 <web copy>` (all three are under
4 MB, so they are not re-encoded).
